# Casos de cálculo verificados a mano

Entre 10 y 15 casos con **respuesta conocida**, calculada a mano antes de escribir el código.
Son el criterio de validación de la etapa 2 y la defensa más fuerte ante el profesor:
el criterio es binario — se reproducen exactamente o no.

Cada caso debe documentar:

1. Las entradas.
2. El resultado esperado.
3. **Por qué** ese es el resultado esperado (el cálculo a mano, escrito).
